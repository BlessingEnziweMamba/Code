🏛 Municipality Info & Services Portal

ALGORITHM DOCUMENT — CIVILIAN-FACING SYSTEM

1. Problem Statement

Design a Python console application that allows civilians to access general municipal information and services. The system must present a navigable menu, route the user to the correct section, display relevant service information, and loop until the user chooses to exit.

2. Inputs & Outputs
TypeDescriptionExample
INPUTMain menu choice (integer string)"1", "2", "0"
INPUTService sub-menu choice"3" → Roads & Stormwater
INPUTENTER key to returnpress ENTER
OUTPUTFormatted text menusMenu with numbered options
OUTPUTService detail (contact, steps)Contact + 4-step guide
OUTPUTFAQs, Emergency contacts, AboutPrinted to terminal
OUTPUTError message on invalid input"⚠ Invalid choice"
3. Main Algorithm (Pseudocode)
BEGIN  MunicipalityPortal

  // ── Initialisation ──────────────────────────────────────
  LOAD  SERVICES_DATA    // dictionary: key → {name, description, contact, steps}
  LOAD  FAQS_LIST         // list of (question, answer) tuples
  LOAD  EMERGENCY_CONTACTS // dictionary: service → phone number

  // ── Main Loop ───────────────────────────────────────────
  running ← TRUE

  WHILE  running  DO

      DisplayMainMenu()          // print numbered options 0–4
      choice ← ReadInput()       // get civilian's keypress

      IF  choice = "1"  THEN
          BrowseServices()       // → sub-algorithm A

      ELSE IF  choice = "2"  THEN
          DisplayFAQs()          // → sub-algorithm B

      ELSE IF  choice = "3"  THEN
          DisplayEmergencyContacts()  // → sub-algorithm C

      ELSE IF  choice = "4"  THEN
          DisplayAbout()         // → sub-algorithm D

      ELSE IF  choice = "0"  THEN
          PrintFarewellMessage()
          running ← FALSE        // exit the loop

      ELSE
          PrintError("Invalid choice. Try again.")
          WaitForEnter()

      END IF

  END WHILE

END  MunicipalityPortal
Sub-Algorithm A — Browse Services
BEGIN  BrowseServices

  browsing ← TRUE

  WHILE  browsing  DO

      PrintServicesList(SERVICES_DATA)   // numbered list of services
      svcChoice ← ReadInput()

      IF  svcChoice = "0"  THEN
          browsing ← FALSE               // return to main menu

      ELSE IF  svcChoice ∈ SERVICES_DATA.keys  THEN
          service ← SERVICES_DATA[svcChoice]
          DisplayServiceDetail(service)     // show name, contact, steps
          WaitForEnter()

      ELSE
          PrintError("Invalid selection.")
          WaitForEnter()

      END IF

  END WHILE

END  BrowseServices


BEGIN  DisplayServiceDetail(service)
  Print(service.name, service.description)
  Print(service.contact, service.hours)
  FOR  i = 1 TO LENGTH(service.steps)  DO
      Print("Step " + i + ": " + service.steps[i])
  END FOR
END  DisplayServiceDetail
Sub-Algorithms B, C & D — FAQs / Emergency / About
BEGIN  DisplayFAQs
  FOR EACH  (question, answer) IN FAQS_LIST  DO
      Print(question)
      Print(answer)
  END FOR
  WaitForEnter()
END  DisplayFAQs


BEGIN  DisplayEmergencyContacts
  FOR EACH  (service, number) IN EMERGENCY_CONTACTS  DO
      Print(service, number)
  END FOR
  WaitForEnter()
END  DisplayEmergencyContacts


BEGIN  DisplayAbout
  Print("Portal description, website, email, last updated.")
  WaitForEnter()
END  DisplayAbout
6. Algorithm Analysis
ComponentTime ComplexitySpace ComplexityNotes
Main loop O(n) O(1) n = number of interactions
Display services list O(s) O(1) s = number of services (constant 6)
Display FAQs O(f) O(1) f = number of FAQs (constant 5)
Dictionary lookup O(1) O(1) Hash map — constant time lookup
Overall program O(n) O(1) Linear in user interactions; constant extra space
